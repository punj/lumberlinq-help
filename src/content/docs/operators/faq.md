**Where do I manage my mill operators?**

Inventory → Operators.

**Why can't I deactivate an operator?**

They still have active (in-progress or draft) tasks assigned. Reassign or complete those tasks first, then deactivate.

**Can I permanently delete an operator?**

No — there's no hard delete, only Deactivate/Reactivate, so task history is always preserved.

**Where do "My Tasks" show up for a mill operator?**

There's no standalone "My Tasks" page. Active processing runs assigned to you appear as a "My Active Mill Tasks" card grid on your Dashboard.

**Why didn't the output tally totals pre-fill?**

That only happens when the run's output was linked to a tally sheet and you returned via the in-app link. A run without that linkage needs output values entered manually.

**Is there a separate "Machine" module?**

Yes — see Command Center's Machines tab (`/inventory/machines`) for adding, importing, and checking the status of equipment. Each Location also has a Machines Installed field listing what's at that site.
